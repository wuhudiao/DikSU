# DikSU

DikSU 是基于 [KernelSU](https://github.com/tiann/KernelSU) 的 Android 内核级 Root 方案分支，在原版能力之上提供了更完整的界面定制能力。

## 特性

- **三档界面风格**：`miuix(美化版)` / `miuix(原版)` / `Material 3`，在设置中自由切换；原版与 MD3 与官方初始布局一致
- **美化版 UI**：图片 / 视频壁纸背景、玻璃拟态导航与面板、可调背景暗度
